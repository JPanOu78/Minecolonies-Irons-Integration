# Minecolonies Iron's Integration

Integration mod between **MineColonies** and **Iron's Spells 'n Spellbooks** & **Iron's Arms 'n Artifice** for Minecraft 1.21.1 (NeoForge).

## Features
- **Mage Guard Job**:
  - Researched in University under **Combat** branch (**Level 1**).
  - Unlocked in **Guard Tower** (and Barracks Tower).
  - Equips and uses spellcaster equipment (Spellbooks, Staves, Wands, Mage Robes) like a player.
  - Tactical ranged spellcasting with Fireball, Frost/Ice Shard, Lightning Bolt, and Arcane Blast.
- **Gunner Guard Job**:
  - Researched in University under **Combat** branch (**Level 1**).
  - Unlocked in **Guard Tower** (and Barracks Tower).
  - Equips and uses firearms from Iron's Artifice (Muskets, Pistols, Blunderbusses, Rifles) and ammunition.
  - Volley firing patterns with reload cycles, smoke and muzzle flash particles, and knockback effects.
- **University Research**:
  - `minecolonies:combat/mage`: Arcane Mastery (Level 1 Combat Research)
  - `minecolonies:combat/gunner`: Firearms Training (Level 1 Combat Research)
- **MCA Compatibility**:
  - Works seamlessly alongside `MCA x Minecolonies` for 3D human models, combat stance animations, and uniform assignments.
